# Gurramkonda Sharun Prakash — Portfolio

Personal developer portfolio built with React, TanStack Start, TypeScript, Tailwind CSS and Vite.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Project structure

- `src/components/portfolio/` — portfolio sections and navigation
- `src/data/portfolio.ts` — portfolio content and verified profile links
- `src/routes/` — application routes and metadata
- `src/styles.css` — global design system and responsive styling
- `public/` — static assets

Project repository/live-demo buttons are only shown when a genuine URL is configured. The resume button is also hidden until a resume file is explicitly added and linked in `src/data/portfolio.ts`.
